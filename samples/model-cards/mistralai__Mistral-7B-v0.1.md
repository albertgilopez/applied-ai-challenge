# Model Card for Mistral-7B-v0.1

The Mistral-7B-v0.1 Large Language Model (LLM) is a pretrained generative text model with 7 billion
parameters. Mistral-7B-v0.1 outperforms Llama 2 13B on all benchmarks we tested.

## Notice

Mistral 7B is a pretrained base model and therefore does not have any moderation mechanisms.
