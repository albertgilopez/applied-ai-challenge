# Review a change before it is merged

`change.diff` is a pull request to `power.py` (the file after the change is in the directory too). It
adds two helpers for the KX-100 power log. The meter's manual is `MANUAL.md`.

Review the change as you would before approving it, and write the review in `REVIEW.md`: what is wrong
(if anything), where, and what the author should do. Say whether you would approve it.

You may change `REVIEW.md`. Changes to other files are not kept.
